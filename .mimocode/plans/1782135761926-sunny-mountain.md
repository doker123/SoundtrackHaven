# План: реализация аудиоплеера на главной странице

## Контекст
HTML-разметка плеера уже есть в `index.html` (строки 37–88): `<audio id="player">`, кнопки play/pause/prev/next/shuffle/repeat/like/volume, прогресс-бар `<input type="range" id="progressBar">`, отображение названия и времени. JS-файлов и аудио нет.

## Что делаем

### 1. Создаём `js/player.js`
Единый файл логики плеера:

**Базовое воспроизведение:**
- Привязка к `<audio id="player">`
- Кнопка play/pause — переключает `audio.play()` / `audio.pause()`, меняет иконку
- Кнопки prev/next — переключают треки из плейлиста

**Прогресс-бар:**
- Обновление `<input type="range">` по событию `timeupdate`
- Клик по прогресс-бару — перемотка (`seekTo`)

**Отображение времени:**
- Форматирование `currentTime / duration` в `MM:SS`
- Обновление `.time` при `timeupdate`

**Плейлист (массив объектов):**
```js
const tracks = [
  { title: "Название трека", src: "music/audio.mp3" },
  // ...
];
```
- Текущий индекс трека
- shuffle — случайный порядок
- repeat — повтор текущего/всего плейлиста

**Громкость:**
- Кнопка volume — toggle mute/unmute
- (Опционально) слайдер громкости

### 2. Подключаем скрипт в `index.html`
Добавить перед `</body>`:
```html
<script src="js/player.js"></script>
```

### 3. Структура папки music
Пользователь кладёт MP3-файлы в `music/`:
```
music/
  track1.mp3
  track2.mp3
  ...
```
В JS-массиве `tracks` прописываются пути к ним.

## Файлы для изменения
- **Создать:** `js/player.js`
- **Изменить:** `index.html` (добавить `<script>`)

## Верификация
1. Положить тестовый MP3 в `music/`
2. Открыть `index.html` в браузере
3. Нажать play — музыка играет, прогресс-бар двигается, время обновляется
4. Нажать pause — музыка останавливается
5. Клик по прогресс-бару — перемотка
6. Кнопки prev/next переключают треки
